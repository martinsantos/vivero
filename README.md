## 🧹 DEPURACIÓN MASIVA DE IMÁGENES - OCTUBRE 2025

### ✅ Limpieza Completa del Sistema de Imágenes (15 de Octubre 2025)

**Problema identificado:** Gestión caótica de imágenes con 55,215 archivos en biblioteca, 99.8% sin uso, duplicados masivos y filesystem con 797 archivos (689 huérfanos).

**Solución implementada:** Sistema automatizado de depuración en 3 pasos con scripts Python y limpieza vía SSH.

#### 📊 Métricas Antes/Después

| Métrica | Antes | Después | Mejora |
|---------|-------|---------|--------|
| **Imágenes en biblioteca** | 55,215 | 108 | -99.8% ✅ |
| **Imágenes sin usar** | 55,109 (99.8%) | 2 (1.9%) | -99.96% ✅ |
| **Duplicados por hash** | Desconocido | 0 | 100% ✅ |
| **Archivos en filesystem** | 797 | 108 | -86.4% ✅ |
| **Archivos huérfanos** | 689 | 0 | -100% ✅ |
| **Productos con imagen** | 538 (100%) | 538 (100%) | Mantenido ✅ |
| **Imágenes únicas usadas** | 106 | 106 | Preservado ✅ |

#### 🛠️ Proceso de Depuración

**Paso 1: Eliminación de imágenes sin usar**
```bash
python3 limpiar_imagenes_eficiente.py --paso 1 --dry-run   # Análisis
python3 limpiar_imagenes_eficiente.py --paso 1 --ejecutar  # Ejecución
```
- **Resultado:** 55,109 imágenes eliminadas vía API REST
- **Duración:** ~4.5 horas (eliminación masiva)
- **Errores:** 0

**Paso 2: Consolidación de duplicados por hash SHA1**
```bash
python3 limpiar_imagenes_eficiente.py --paso 2 --dry-run   # Análisis
python3 limpiar_imagenes_eficiente.py --paso 2 --ejecutar  # Ejecución
```
- **Resultado:** 0 duplicados detectados (biblioteca ya limpia)
- **Hashes únicos:** 106/106
- **Duración:** 1.5 minutos (cálculo de hashes)

**Paso 3: Limpieza de filesystem en servidor**
```bash
python3 limpiar_filesystem_servidor.py --dry-run   # Análisis
python3 limpiar_filesystem_servidor.py --ejecutar  # Ejecución
```
- **Resultado:** 689 archivos huérfanos eliminados del servidor
- **Método:** SSH + WP-CLI + xargs rm
- **Directorios afectados:** 5 (principalmente `2025/10/`)
- **Duración:** 15 segundos

**Paso 4: Regeneración de thumbnails WordPress** ⚠️ **CRÍTICO**
```bash
sshpass -p 'gsiB%s@0yD' ssh root@23.105.176.45 \
  "cd /home/viveroloscocos.com.ar/public_html && \
   wp media regenerate --yes"
```
- **Resultado:** 106 imágenes procesadas, ~636 thumbnails generados
- **Tamaños:** 150x150, 300x300, 600x600, 768x768, 1024x1024
- **Duración:** 30 segundos
- **Nota:** Este paso es **obligatorio** tras cualquier limpieza masiva

#### ⚠️ Incidencia Resuelta: Imágenes Rotas (15 Oct 2025)

**Problema:** Tras la depuración masiva, las imágenes aparecían rotas en producción (solo alt-text visible).

**Causa:** Los thumbnails derivados de WordPress (`*-300x300.webp`, etc.) fueron eliminados durante la limpieza del filesystem y no se regeneraron automáticamente.

**Solución:** Ejecutar `wp media regenerate --yes` vía SSH para regenerar todos los thumbnails.

**Resultado:** 106 imágenes procesadas, 636 thumbnails regenerados, 0 imágenes rotas.

**Documentación completa:** [SOLUCION-IMAGENES-ROTAS-OCTUBRE-2025.md](./SOLUCION-IMAGENES-ROTAS-OCTUBRE-2025.md)
