🔍 HOMEPAGE vs SHOP

Diagnosticando por qué la tienda funciona pero la home no

ISSUE FOUND FIX APPLIED TESTING

🕵️ PROBLEMA IDENTIFICADO

ROOT CAUSE: El JavaScript del carousel y los scripts de WooCommerce AJAX solo se cargan en `is_front_page()`, pero el homepage requiere funcionalidad WooCommerce completa.

✅ TIENDA (Funciona)

  • URL: /tienda/
  • Template: WooCommerce shop template
  • Scripts: WooCommerce AJAX scripts automáticos
  • Botones: Funcionan perfectamente
  • Reason: WooCommerce maneja todo automáticamente

❌ HOMEPAGE (No funciona)

  • URL: / (root)
  • Template: front-page.php
  • Scripts: Solo carousel JS, sin WooCommerce AJAX
  • Botones: No responden
  • Reason: Falta integración WooCommerce

🔧 SOLUCIÓN IMPLEMENTADA

FIX 1: Extendí la condición de carga de WooCommerce scripts para incluir `is_front_page()`
FIX 2: Agregué localización específica de parámetros WooCommerce AJAX para el homepage
FIX 3: Aseguré que los scripts se cargan en el orden correcto con dependencias
ANTES (functions.php): // Scripts WooCommerce solo en páginas WooCommerce if (function_exists('is_woocommerce') || function_exists('is_cart') || function_exists('is_checkout')) { wp_enqueue_script('wc-add-to-cart'); } DESPUÉS (functions.php): // Scripts WooCommerce en páginas WooCommerce + HOMEPAGE if (function_exists('is_woocommerce') || function_exists('is_cart') || function_exists('is_checkout') || is_front_page()) { wp_enqueue_script('wc-add-to-cart'); wp_enqueue_script('wc-cart-fragments'); wp_enqueue_script('woocommerce'); } // Localización específica para homepage if (is_front_page() && function_exists('WC')) { wp_localize_script('loscocos-home-carousel', 'wc_add_to_cart_params', array( 'ajax_url' => WC()->ajax_url(), 'wc_ajax_url' => WC_AJAX::get_endpoint('%%endpoint%%'), // ... más parámetros WooCommerce )); }
