# Base Firme World-Class Commerce Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the active WooCommerce theme buildable, lint-clean, safer, and operationally auditable before catalog and UX work begins.

**Architecture:** Keep production on `theme-loscocos-child` with parent `theme-loscocos`, but restore the child theme as the single owned UI surface. Add small repeatable audit scripts instead of relying on manual terminal checks. Defer broad visual redesign until build, PHP, security, and health checks are stable.

**Tech Stack:** WordPress, WooCommerce, PHP 7.4-compatible theme code, Tailwind/PostCSS in `theme-loscocos-child`, shell scripts, WP-CLI for production checks.

---

## Task 6: Add Commerce Health Script

**Files:**
- Create: `scripts/audit/commerce-health.sh`

- [ ] **Step 1: Create the script**

Create `scripts/audit/commerce-health.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

ROOT="$(cd "$(dirname "$0")/../.." && pwd)"
cd "$ROOT"

echo "== PHP lint: theme-loscocos-child =="
for f in $(find theme-loscocos-child -path '*/node_modules' -prune -o -name '*.php' -print); do
  php -l "$f" >/tmp/loscocos_php_lint.out 2>&1 || {
    echo "FAIL: $f"
    cat /tmp/loscocos_php_lint.out
    exit 1
  }
done
echo "OK"

echo "== CSS build =="
(cd theme-loscocos-child && npm run build)

echo "== Local secret scan =="
if scripts/audit/secret-scan.sh; then
  echo "OK: no obvious active secrets"
else
  echo "WARN: secret scan found matches; review output above"
fi

echo "== Done =="
```

- [ ] **Step 2: Make it executable**

Run:

```bash
chmod +x /Applications/um/vivero/scripts/audit/commerce-health.sh
```

- [ ] **Step 3: Run health check**

Run:

Expected after Tasks 1-5: PHP lint and CSS build pass. Secret scan may still warn until cleanup is complete.
