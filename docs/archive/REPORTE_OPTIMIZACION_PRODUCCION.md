## 🚀 SCRIPTS DESARROLLADOS

### 1. `audit_vivero_fast.py`
**Propósito:** Auditoría rápida de productos usando consultas SQL directas

**Funcionalidades:**
- Obtiene todos los productos en una sola consulta
- Detecta imágenes duplicadas
- Identifica productos sin imagen
- Analiza calidad SEO de títulos y descripciones
- Genera reporte JSON completo

**Uso:**
```bash
python3 audit_vivero_fast.py
```

### 2. `fix_products_seo.py`
**Propósito:** Optimización automática de SEO para productos problemáticos

**Funcionalidades:**
- Actualiza títulos con palabras clave
- Genera descripciones cortas optimizadas
- Crea descripciones largas con HTML semántico
- Aplica cambios directamente en producción vía WP-CLI

**Uso:**
```bash
python3 fix_products_seo.py
```

### 3. `assign_missing_images.py`
**Propósito:** Asignación automática de imágenes desde APIs gratuitas

**Funcionalidades:**
- Busca imágenes en Unsplash y Pexels
- Descarga imágenes de alta calidad
- Sube a WordPress Media Library
- Asigna como imagen destacada del producto
- Maneja rate limits y errores

**Uso:**
```bash
python3 assign_missing_images.py
```
