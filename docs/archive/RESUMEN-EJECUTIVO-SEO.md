## 🔧 IMPLEMENTACIÓN

### Fase 1: Preparación (15 minutos)
1. ✅ **Backup de base de datos**
   ```bash
   ssh root@23.105.176.45
   wp db export backup_antes_seo_$(date +%Y%m%d).sql
   ```

2. ✅ **Obtener credenciales API de WooCommerce**
   - WooCommerce > Settings > Advanced > REST API
   - Generar Consumer Key y Secret

3. ✅ **Ejecutar análisis previo**
   ```bash
   python3 analyze_current_titles.py
   ```

### Fase 2: Simulación (15 minutos)
```bash
python3 update_titles_production.py \
  --url https://viveroloscocos.com.ar \
  --key ck_XXXXXXXXXX \
  --secret cs_XXXXXXXXXX \
  --dry-run \
  --limit 50
```

**Validar:**
- ✓ Títulos generados son correctos
- ✓ Sin errores de conexión
- ✓ Formato es apropiado

### Fase 3: Ejecución (1-2 horas)
