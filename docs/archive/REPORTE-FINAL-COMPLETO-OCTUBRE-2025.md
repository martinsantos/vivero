## 💡 LECCIONES APRENDIDAS

### Técnicas

1. **Queries de búsqueda ecommerce:** Agregar contexto "product photo", "ecommerce", "white background" mejora significativamente la calidad de imágenes obtenidas.

2. **Global deduplication:** Evitar duplicados entre productos mejora la percepción visual del catálogo.

3. **Fallback progresivo:** Intentar múltiples providers (Pixabay, Unsplash, Wikimedia) aumenta la tasa de éxito.

4. **Optimización incremental:** Dividir el trabajo en fases permite ajustar estrategias sobre la marcha.

### Estratégicas

1. **CSS-only redesign:** Implementar cambios visuales vía CSS custom evita modificar templates y preserva funcionalidad.

2. **Documentación continua:** Generar documentación durante el proceso facilita revisiones y mantenimiento futuro.

3. **Testing incremental:** Verificar cada fase antes de continuar previene problemas acumulativos.
